How to read this

  • Scores from 2022–24 come from a model trained through 2024, so those months are in-sample and look better than a real test. Only 2025 and 2026 are a true forward test.
  • The chance estimate is a simple curve fitted on 2022–24 scores from a model trained to 2021. It is checked here each season and should be refitted if the dots drift off the line.
  • The 2026 season starts in April in this data, so there are no January to March points.
  • Numbers come from monitoring/export_monitoring_tables.py, which writes a small summary file with no raw fire records.
